# Customer Segmentation Analysis Using Python

## Project Overview

This project performs customer segmentation using Python and machine learning techniques on the Online Retail transaction dataset.

The project uses **RFM analysis (Recency, Frequency, Monetary)** to understand customer purchasing behavior and **K-Means clustering** to group customers with similar transaction patterns. The results help identify valuable customers, loyal customers, recently acquired customers, and customers who may be at risk of becoming inactive.

## Objectives

* Clean and prepare online retail transaction data.
* Analyze sales and customer purchasing behavior.
* Calculate Recency, Frequency, and Monetary values.
* Assign RFM scores to customers.
* Classify customers into meaningful segments.
* Apply K-Means clustering to RFM features.
* Evaluate clustering using the silhouette score.
* Visualize customer segments and cluster patterns.
* Generate business insights and export results.

## Dataset

The notebook loads the Excel file `Online Retail.xlsx` and reads the worksheet named `Online Retail`.

The dataset contains online retail transaction information, including fields such as InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, and Country.

**Important:** Place the Excel file in the notebook's working directory before running the notebook. Check the dataset's source and terms before redistributing it publicly.

## Project Workflow

### 1. Data Loading and Inspection

Load the Excel dataset and inspect its shape, columns, data types, missing values, duplicates, and descriptive statistics.

### 2. Data Cleaning

* Remove duplicate transactions.
* Remove records without a CustomerID.
* Convert required fields to appropriate data types.
* Remove invalid records.
* Exclude cancelled invoices.
* Keep transactions with positive quantities and unit prices.

### 3. Sales Calculation

Calculate the transaction sales amount:

`TotalSales = Quantity × UnitPrice`

### 4. Customer Summary

Aggregate transactions by CustomerID to calculate total sales, number of orders, total quantity, last purchase date, and country.

### 5. RFM Analysis

RFM stands for:

* **Recency:** Number of days since the customer's last purchase.
* **Frequency:** Number of distinct invoices for the customer.
* **Monetary:** Total sales generated by the customer.

The notebook calculates RFM values and assigns scores from 1 to 5. Recency scoring is reversed so that more recent purchases receive higher scores.

### 6. Customer Segmentation

Customers are assigned to the following segments using RFM scores:

* Champions
* Loyal Customers
* Recent Customers
* At Risk
* Hibernating
* Potential Loyalists

### 7. K-Means Clustering

The notebook applies a log transformation to the RFM features, standardizes them using StandardScaler, and applies K-Means clustering.

The elbow method is plotted to examine possible cluster counts. The notebook then fits a four-cluster K-Means model and calculates the silhouette score.

### 8. Visualization

The notebook generates:

* Recency, Frequency, and Monetary distribution plots
* Customer count by segment
* Revenue by customer segment
* Elbow method plot
* K-Means customer cluster scatter plot
* Average RFM score heatmap by segment

### 9. Business Insights

The notebook identifies:

* The largest customer segment
* The segment generating the highest total revenue
* The segment with the highest average spending
* The segment with the most recent purchases on average

### 10. Export Results

The notebook exports customer-level RFM scores and segments, along with segment and cluster summaries.

## Key Outputs
